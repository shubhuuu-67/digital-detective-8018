# Mission 1 - Know your computer

## 1. Task / objective
Understand how a computer takes input, processes data, shows output, and saves files (IPOS). Classify common hardware and software items, and look at three everyday machines that work like computers.

## 2. Work completed

**Task 1.1 - Trace one activity using IPOS**
Activity: Typing and saving a Python file in VS Code.

| Stage | What happens in your example? | Possible hardware/component |
| :--- | :--- | :--- |
| Input | I type my code on the keys and press Cmd + S to save the file. | Keyboard and trackpad |
| Processing | The processor reads the key presses, runs VS Code, and keeps the unsaved code in temporary memory. | CPU and RAM |
| Output | The letters and colors show up on the screen right away so I can see what I wrote. | Laptop screen |
| Storage | When I hit save, the file gets written from temporary memory onto permanent storage so it stays there even after I shut down. | Internal SSD |

How it moves from start to finish: When I press a key, the keyboard sends signals to the CPU, which processes them while holding the open file in RAM. At the same time, the laptop sends the updated text to the screen so I can read it, and pressing save copies the file onto the SSD so it does not get lost.

## 4. My understanding
Pretty much anything we do on a computer follows the IPOS cycle. First, an input device like a keyboard sends data in, then the CPU and RAM handle the actual work, the screen shows the result, and the SSD saves it for later. Hardware is the physical parts you can touch, while software is the code telling those parts what to do. Even everyday machines like an ATM or a metro ticket kiosk work the exact same way, just built to do one specific job.
