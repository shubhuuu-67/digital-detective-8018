**Task 2.2 - Practise file changes safely**

- **Difference between replacing a file's contents and adding text to the end:** Using a single `>` replaces everything inside the file with the new text, while `>>` adds the new line to the bottom without deleting existing lines[cite: 5]. After using both on `log.txt`, `cat log.txt` showed both `First line of notes` and `Second line added safely`, and the file size grew to `45B`.
- **Difference between copying a file and moving a file:** `cp` creates a separate duplicate so both files exist, whereas `mv` renames or moves the original file without creating an extra copy[cite: 5].
- **What information the current-directory display provides:** `pwd` shows the full path from the root directory to the exact folder I am currently inside, which helps confirm I am working in the right place[cite: 5].
- **Why a directory-listing operation is useful:** `ls` lets me check which files and folders exist inside a directory right away from the keyboard[cite: 5].

**Task 2.3 - Understand flags and pipes**

- **Comparing `ls` and `ls -lah`:** Plain `ls` only showed the four visible file names (`log.txt`, `log_backup.txt`, `note.txt`, and `note_renamed.txt`). Running `ls -lah` added detailed permissions and timestamps (`-l`), showed hidden directory entries `.` and `..` (`-a`), and formatted sizes in readable units like `45B` and `0B` (`-h`)[cite: 6].
- **How `ls -l | head -n 5` works:** The pipe symbol (`|`) takes the output generated by the command on the left and passes it directly into the command on the right[cite: 6]. `ls -l` produced the full detailed file list, and `head -n 5` cut that output down to just the first 5 lines (`total 16` plus the four file lines)[cite: 6].

**Task 2.4 - Understand package managers**

Checked Homebrew using `brew --version` and `brew list` without installing or removing anything[cite: 6]. It returned `Homebrew 7.0.11` and listed installed packages like `git`, `openjdk`, and `cowsay`. A package manager installs, updates, and removes command-line tools from a single Terminal command instead of downloading installers manually, and it automatically manages the extra libraries those tools depend on[cite: 6].
