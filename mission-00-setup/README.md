## 4. My understanding
A repository is a central project folder tracked by Git that stores all files along with a complete history of changes made over time. Organizing the repository into separate folders for each mission keeps notes, code, and evidence clean and easy to navigate, while allowing each mission to be tracked and committed independently without mixing unfinished work.
